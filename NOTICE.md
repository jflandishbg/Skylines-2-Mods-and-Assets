# Notice

Cities: Skylines II is a product of Colossal Order and Paradox Interactive. This repository is unofficial and not affiliated with either company.

- No game assemblies, decompiled game source, game meshes or textures are included. Build the C# mods against the DLLs from your own install.
- Some scripts and JSON files refer to vanilla prefab names, GUIDs and settings. Those names belong to the game; they are listed only so the tools can find the right prefabs on your machine.
- Some Lobstertown setup scripts read templates from other mods in your local mod cache. Those mods are not included and keep their own licenses.
- Texture scans and atlas images are left out. If you rebuild them, check the license of each source scan before you redistribute the result.
